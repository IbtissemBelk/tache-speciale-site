# Tache Spéciale – Site vitrine

Site vitrine du spa hammam **Tache Spéciale** (Tunisie), un hammam dédié aux enterrements de vie de jeune fille : la mariée vient avec ses amies et sa famille en tenue traditionnelle pour célébrer la journée du hammam avec musique et brunch.

Thème : **Harim Soltan**.

Instagram : https://www.instagram.com/tache_speciale

## Ouvrir le site

Site statique, sans installation : double-cliquez sur `index.html`, ou servez le dossier (par ex. `npx http-server .`) puis ouvrez l'adresse affichée.

## À compléter

- **Photos** : dans `index.html`, section `#galerie`, remplacer chaque `<figure class="photo ... photo--empty">` par la même figure sans `photo--empty`, avec une `<img src="images/....jpg" alt="...">` à l'intérieur.
- **Prix** : les formules affichent « Prix sur demande » (repérés par `data-placeholder`).
- **WhatsApp** : le bouton utilise le numéro de la bio Instagram (53 335 379). Vérifier qu'il est bien sur WhatsApp.

Les coordonnées (téléphone, horaires, lien Google Maps) viennent de la bio Instagram.
